Taruh gambar-gambar berikut di folder ini (nama file harus persis):

- pen.png          -> ilustrasi pena/bulu di halaman surat
- stamp.png        -> ilustrasi perangko di halaman surat
- bouquet.png      -> ilustrasi buket bunga di halaman bunga
- album-cover.jpg  -> sampul default di kartu pemutar musik
- track1.jpg       -> sampul lagu #1 di playlist (ganti nama di PLAYLIST, app.py, kalau mau beda)
- track2.jpg       -> sampul lagu #2
- track3.jpg       -> sampul lagu #3

Kalau salah satu file belum ada, halaman tetap tampil rapi —
akan muncul kotak putus-putus kecil berisi nama file yang perlu
kalian tambahkan, jadi tidak ada gambar 'broken' yang jelek.

Format PNG dengan latar transparan paling cocok untuk pen.png,
stamp.png, dan bouquet.png. Untuk album-cover.jpg / track*.jpg
bebas JPG/PNG biasa (disarankan rasio persegi, misal 500x500px).
